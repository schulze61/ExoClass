## Python Crash Course
This module is intended to: 
1.  give students with limited Python experience exposure to some basic functions and plotting procedures.
2.  serve as a living/breathing notebook that students can add to as they progress and discover new useful Python tools.
3.  give the course instructor(s) a sense of the level of Python/coding experience of the students.

The notebook currently covers the following topics: 
1.  Using the markdown feature in Jupyter
2.  Importing python packages
3.  Using a function
4.   Defining variables
5.   Handling arrays
6.   Plotting data
7.   How to make a GOOD plot!
8.   User-defined functions
9.   SciPy basics
10.   Figures with multiple panels
