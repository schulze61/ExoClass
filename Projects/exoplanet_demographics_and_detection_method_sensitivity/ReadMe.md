Project description:
The main question to answer is what type of exoplanets have we observed and why?

You are tasked with researching the state-of-the-art performance of the direct imaging, transit photometry, radial velocity, and astrometry exoplanet detection techniques. You will derive approximations for the sensitivity limits of these techniques and plot them on the following plots:
	Transit photometry + direct imaging: radius vs. period and radius vs semi-major axis
	Radial velocity + astrometry: mass vs period and mass vs semi-major axis

You will need to plot the Solar System planets and the two planets from project 1 (HD 189733 b + GJ 1214 b) on all four plots. Additionally, you will need to calculate the detection signals for all 10 of these planets for all 4 detection methods and tabulate the results and answer the following questions:

Are any of them observable with any of the four techniques?
    - Which planets are observable with which techniques? Why?
    - Which planets are unobservable with any of the techniques? Why?
